# Canadian Cheese and Provincial Temperature Analysis

This repository contains a small data analysis project completed for the Canadian Sheep Federation Data Analyst Internship assessment.

The project analyzes the Canadian Cheese Directory dataset and compares cheese production patterns across provinces with average provincial temperature and moisture data.

## Project Objective

The goal of this analysis is to explore whether there are observable relationships between provincial climate patterns and the number or type of cheeses produced in Canada.

The notebook answers the following questions:

- Are there any inferences that can be made about the relationship between weather in a province and cheese production?
- How does the number of cheese varieties differ across provinces?
- Which provinces dominate cheese production in the dataset?
- Are cheese varieties more strongly related to climate or to provincial production concentration?
